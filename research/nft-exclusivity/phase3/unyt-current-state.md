A template supplies code, definition and runtime schemas, output schema, options and agreement rules. An agreement instance fixes its role qualifications, input rules and execution authority. A parked spend supplies a source to be consumed. Data links may have different consumption semantics. A RAVE records execution. An allocation names sources, amounts by unit and a receiver. Receipt, commitment, accept, reject and reclaim are distinct record types in the public crate. Exact amount arithmetic, consumption, collection and exclusive terminal disposition are different checks. Execution code cannot infer absence from an empty lookup.

The public conditional_forward selects a consumed receiver or return address based on condition_met. Its sample declares that boolean ExecutorProvided and executor Any. The lockbox script carries previous_execution.output.locked, names parked sources, makes source-only allocations with empty amounts, and allows executor-driven unlock to executor_pub_key. Its ordinary payout names payout_receiver from input. This is a building block for a trusted operator. The seller cannot deduce irrevocable payment from the existence of either script. Verify instance rules, parties, exact unit amounts and source identity as well as template bytes.
