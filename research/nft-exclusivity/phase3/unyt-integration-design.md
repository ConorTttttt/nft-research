# Boundaries of a production adapter

The proposed adapter must verify an authenticated reservation, debit and terminal disposition tied to the exact template, agreement instance, source DNA, unit definitions, buyer, seller, amounts and consumed input. The instance must fix the beneficiary. Value rules use exact units. Exclude unsupported lanes, fees, mixed units and ambiguous identity mappings. A signed mapping between payment identities and NFT controllers needs both parties' consent and a pinned realm. Only the test realm currently aliases 32-byte key cores; the native runner wraps these as synthetic Holochain keys. A template byte hash in this lab is not a production agreement instance hash.

The public engine provides useful evidence reads, but a portable verifier needs the source records and an authoritative rule establishing final disposition across competing histories, including reclaim, fork and migration. A projected output, supplied RAVE hash or general notary close attestation cannot supply that rule. If Unyt supplies only branch-local validity, either keep both assets inside a common trusted settlement ledger, explicitly price a counterparty guarantee, or leave the transaction pending. A bridge promising redemption adds a separate backing invariant.

The native runner is a pure execution adapter for the pinned hNFT template. Its synthetic funded coupon has exact price and a unique source in a test-only SQLite ledger. The payment machine checks the allocation before advancing. A caller cannot set a completion boolean. The verified title rule depends only on the small pinned profile and issuer statement. Running arbitrary commercial scripts in the title verifier would expand the trusted code base and create pricing and host-call dependencies in every title check.

For UI, show listed, certified and awaiting funds, reserved, settled and awaiting proof retrieval, vested and published, rejected evidence, and unresolved as independent statuses. A verified void is distinct from a CEL closure refund. Display which authority signed each and whether funds are merely allocated, collected, or irrevocably credited. The inspector's captured execution is appropriate for an economic preview.
