# Decision for Phase 4

Select certified resource transitions with predetermined settlement grants. Keep one durable decision at each genuine point of incompatible choice. Use the rights model to place that decision at the smallest stable set of relevant facets. Use a historical certificate to carry contractual meaning across apps, and a separately authenticated terminal fact to vest the preselected outcome. This architecture retains the Phase 2 exclusivity proof and adds an independently testable economic premise.

For the sale, the commercial code computes a price allocation, the payment authority resolves paid/void once, and the NFT witnesses certify the initial commitment. The integrated prototype exercises and resells a grant without asking the seller to sign again. The second discretionary sale requires new votes. The single terminal issuer is a substantial additional trust assumption. A party requiring native, independently verifiable Unyt money still has an unresolved integration requirement.

## Answers to the research questions

| Question | Result |
|---|---|
| A. Reusable sources | CEL voters, journals and proof code; hNFT mint/metadata and exact-sale Rhai; rave_engine; exact-status read pattern; dex_core arithmetic. Snapshot vectors and FROST custody are conditional candidates. |
| B. Unyt guarantees | Reproduced deterministic sample execution. Source confirms typed records and scoped evidence reads. Independently irreversible debit and reclaim exclusion across forks and migration remain unverified. |
| C. Fewer witness decisions | Yes, if parties, guards and release branches are bound before payment and terminal evidence has mutually exclusive semantics. No post-payment NFT vote for exercise. |
| D. Minimal coordination | Least coordinate support is computable for explicit finite Cartesian transition tables. Stable reads also need fencing. Neither participant count nor a globally optimal protocol for arbitrary programs follows from this result. |
| E. Fair exchange | Conditional vested entitlement with an honest irrevocable ledger and recoverable proof. No unconditional simultaneous materialization, bounded resolution, or verified production Unyt atomic exchange. |
| F. Compressed history | A quorum replay-and-sign checkpoint reduced the buyer payload and CPU at tested depth. Issuers incurred replay cost and must implement an additional correct checkpoint duty. No current-owner claim. |
| G. Threshold cryptography | Potential 256 raw signature bytes saved at q=5. Nonce fencing, rounds, accountability, share lifecycle and rollback assumptions outweigh this for the initial pilot. |
| H. General rights | Versioned facets cover title, lease, delegation and prospective policy changes. Revocation needs an intersecting exercise guard or explicitly weaker offline acceptance. |
| I. Composition failures | Identity/unit substitution, duplicate import, stale but valid history, per-executor locks, fork-local reclaims, missing dependencies and hidden terminal evidence. |
| J. Superior architecture | The hybrid improves coordination placement and verification cost for scoped use cases. No evidence supports replacing CEL for unrestricted choice or ranking architectures independently of economic custody assumptions. |
| K. Research contribution | Precise guarded sale/lease example, finite dependency oracle, concrete grant-installation rule, measured proof profile and integration evidence. Quorum intersection, certified checkpoints and precommitment are established ideas. |
| L. Next priority | Prove payment disposition and evidence availability on the real source domain, then implement controlled mint/export and multi-generation certified rights. |

## Acceptance gates

A passes for the reproduced Phase 2 models, process benchmarks, Rust tests and 0.7.1 conductor fixture. Component replication is partial. B and C pass within their reported finite domains, with the stated inductive assumptions. D passes as an honest boundary assessment; production native payment finality remains open. E passes for bounded buyer verification and payload costs. F passes for the local test-asset vertical slice only. G records unresolved trust and operational requirements. No gate authorizes production use.
