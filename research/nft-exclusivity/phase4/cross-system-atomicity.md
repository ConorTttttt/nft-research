# Failure model and acceptance boundary

The selected contract compares *entitlements*. One irreversible decision vests both. Possession of complete proof, ability to respend a credit, and delivery to both parties are additional conditions. A local credit followed by an unverifiable NFT grant leaves the payer exposed if a marketplace calls that sequence atomic.

| Interruption or adversary | Required behavior |
|---|---|
| Alice disappears before title reservation | Buyer must verify the certified grant before authorizing any irreversible debit. A native script needs an enforceable equivalent. |
| Alice disappears after grant, Bob after park | Fixed beneficiaries remove later seller choice. An absent buyer before the required terminal authorization can lock both sides. |
| Executor crashes before or after assembly | Retry identical evidence. A partially signed outcome can block alternatives. Once a certificate can exist, lack of a published copy authorizes no refund. |
| Payment or NFT evidence withheld across DNAs | A reader stays Pending. Independent complete archives can restore usability under stated survival limits. A real credit already collected can be economically one-sided while the buyer lacks usable title. |
| Settlement and reclaim race, payer forks, credit changes | All incompatible recognized exits must consume the same fenced capacity. A per-agreement terminal decision misses alternative grants, and a native bypass defeats an overlay. |
| Seller signs competing hNFT histories | The CEL parent has a pinned decision policy. Legacy circulation remains a separate acceptance domain until the source enforces export. |
| Stale RAVE, different network, altered parties or amount | Bind exact version, DNA, identities, funded source and grant. Exact replay can only identify the same entitlement. A valid old certificate cannot attest current control. |
| Clock deadline or backdated action | A deadline can restrict admissible proposals. A past deadline does not exclude a hidden paid certificate. |
| Committee rollback or unavailable quorum | Non-equivocation covers the entire validity horizon, including restored keys. Unavailability stops progress. Permanent close requires the Phase 2 exclusion predicate, and an independent native exit must also be fenced. |
| Agreement/DNA migration or key compromise | Require the old recognized authority to certify export and permanently close the original input. New keys cannot adjudicate an unresolved old grant. Owner compromise permits actions its policy already authorizes. Witness compromise consumes the lifetime equivocation budget. |

Conditional progress requires a reachable agreeing quorum before incompatible locks form, valid authorizations, fair message delivery, available execution dependencies and surviving complete evidence. A partition or irreconcilably split votes can stall forever. The bounded model treats vesting as part of the definition of certificate recognition; it cannot verify an external ledger honors that definition.
