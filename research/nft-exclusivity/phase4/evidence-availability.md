# What must survive the executor

There are two completion boundaries. First, signatures can already establish a unique payment disposition while nobody else can assemble them. Second, a recipient can hold all authoritative dependencies and exercise the deterministic title. A vote lock, statement digest or Merkle root does not let a new process derive the missing signature or reconstruct an unavailable path.

The test materializes the complete source policy, NFT grant, roles, buyer authorization, payment votes and disposition into one self-contained envelope. The independent reader already trusts the source root and expected grant ID. Four of the seven payment participants each commit the complete bytes to a separate SQLite database before acknowledging their hash under a separate archive domain. Recovery uses one database in read-only mode after the producer process has exited and its temporary files and keys have been removed. The separate Rust verifier needs only the public roots and the bytes. The Python trial also checks an onward authorized transfer using recovered evidence. This is logical replica isolation on one machine. A lost disk holding all replicas is outside the survival assumption.

For r complete copies, at most f withholding copies and l other permanent losses, one is guaranteed accessible after eventual delivery iff r>f+l under arbitrary independent placement of these identities. At r=4, f=2, l=1 this is tight. Each replica must retain the *whole* object and dependencies. Seven archive locations holding only the grant cannot reconstitute an independently lost payment certificate. An erasure-coded implementation would need the decoding threshold of independent honest shards. Historical tree proofs need the branch and certified root; checkpoint signers must either serve those or replicate a reconstructible manifest.

The archive barrier follows assembly. A crash between decision and the fourth acknowledgment remains a potential permanent stall. Calling payment “delivered” before that barrier is unwarranted. A stronger protocol can require the bytes to be durably available before both domains recognize external vesting, and can reissue identical acknowledgments after restart. This changes both domains' acceptance contracts; it cannot delay recognition of a native Unyt credit unilaterally. Replicating bodies also has privacy and retention costs.

In native Unyt, recovering records from a second agent is valuable historical evidence. No number of replicas holding identical historical records creates the missing economic exclusion statement. Conversely, exclusivity without retrievability can leave a buyer unable to act permanently.

**Native recovery demonstrated.** A second cell retained five validated historical records. A fresh reader, after the disposable conductor had stopped, verified their action signatures and authenticated entry contents using only the capture, verifier and fixture pins. The recovered seller receipt binds the signed execution and the received ten units. One surviving offline copy sufficed in this run.
