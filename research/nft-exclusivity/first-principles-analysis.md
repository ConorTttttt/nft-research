# Local information and exclusive choice

Consider a Byzantine seller holding a copyable signing key. In one execution only buyer B appears. In a second only C appears. Suppose each accepts irreversibly on a finite transcript obtainable with its side of a partition. Freeze the seller's initial state twice. Interleave the two transcripts, delay all cross-partition traffic, and allow every common Byzantine process to answer both. Each buyer sees exactly its accepting prefix. Eventual delivery cannot undo either decision. The argument applies to randomised protocols conditional on compatible accepting coins. A sampled witness set can yield a quantified failure probability instead of absolute safety.

The premise fails if both traces require an honest durable one-use decision, if the destination was fixed in a shared prefix, if a trusted physical device serialises signatures, or if one side waits. Consensus on a total order of all NFTs is stronger than necessary. Consistent broadcast scoped to one writer and version can provide uniqueness even when an equivocating writer prevents delivery. Demanding termination for contested inputs changes the problem.

In a grow-only set of signed events, union merges replicas. Two individually valid singleton spends merge to an invalid set. Exclusive choice fails invariant confluence. A deterministic winner repairs eventual convergence at the cost of reversing earlier acceptance. For two permanently independent rights, product state and componentwise transitions commute. A read dependency can invalidate this decomposition. If sale promises a vacant title, an outstanding lease changes the truth of that promise. [Bailis et al.](https://arxiv.org/abs/1402.2237)

Conservation moves coordination to the allocation that partitions a budget. An indivisible token has only one unit to allocate. Splitting title and use creates distinct legal entitlements with separate budgets of one. Escrow cannot allocate the same unit to two independent sellers. A linear type can enforce one consumption in a verifier's local execution. Two isolated executions can each type-check. A partition matroid permits at most one chosen successor per parent, but independent local choices need not have an independent union.

Hashes authenticate content, accumulators commit to a specified set, and zero-knowledge proofs can establish validity relative to a committed root. A second root can contain a different valid successor. One-time signatures assume appropriate key use by the signer. Classical secret bits and the state needed to sign can be copied. Forward security with real erasure can bound retrospective forgery. None of these mechanisms independently orders two authorised messages. An analogy to a conservation law or quantum no-cloning supplies no physical enforcement in a software conductor.

A staged transfer can move the expensive choice earlier. Certify an irrevocable conditional grant to a fixed recipient, then allow anyone to relay a preimage for a committed hash. Define the child by the grant identity, so duplicate reveals are idempotent. Release requires zero new witness decisions. The right is encumbered from grant time and may stay locked forever. Adding unilateral cancellation, late choice of recipient or a deadline verified only against local time reintroduces incompatible branches.
