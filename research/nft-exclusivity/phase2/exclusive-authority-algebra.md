# Exclusive authority as a resource rewrite

A version carries (domain, right identity, resource extent, controller, admissible policy). Let M be a partial commutative monoid of extents. For the simplest model an extent is a subset of a finite set of rights atoms and composition is disjoint union. A marking contains unique spendable versions. An authorised rewrite consumes named versions I and emits finitely many fresh versions O. Require both products defined and product(O) ≤ product(I), with equality for conserving transfers. Every new extent derives from an input and lies within its delegable policy. IDs derive from the certified statement and canonical output coordinates. Inputs are linear across *certified* rewrites; a local type checker can only establish conservation inside one rewrite.

**Examples.** Partition {title, use} at an agreed transition into a title authority and an independently assignable use authority. Later assignments of disjoint components commute if neither reads a condition changed by the other. A title buyer accepting the continuing lease consumes only title. A vacant-title buyer must also consume a guard representing the ability to create or continue the lease. Delegation with immediate unilateral revocation introduces a shared dependency at exercise. An irrevocable exercise to a predetermined controller is a deterministic rewrite from previously certified authority. Committee handoff changes the policy on a newly certified output. Preserving an input's unresolved state under a different validator set is a different operation.

**Frame condition.** For disjoint consumed versions, require independent output names, local preconditions invariant under the other rewrite, and a frame-preserving postcondition for all unchanged resources. Under these conditions both execution orders lead to the same marking up to permutation. Proof: remove both disjoint input sets, retain the common frame and append both independent output sets. Conversely, merely checking disjoint writes misses read/write conflicts, global supply constraints, dynamic role changes and negative predicates. Checking two unspent inputs does not prove compatibility of arbitrary contract programs.

**Falsification.** A pairwise conflict graph represents exactly systems where every inadmissible set contains an inadmissible pair (a flag complex for downward-closed feasibility). Unit-capacity guards give each guard's users a clique; an edge-clique cover implements such a pairwise relation. A pool allowing any two of three requests supplies a minimal forbidden triple and has no exact pairwise conflict graph. A hypergraph of minimal forbidden sets represents any finite downward-closed feasibility relation, but implementing each hyperedge as one exclusive lock incorrectly rejects pairs. Preallocate counted permits or coordinate where allocation is contested. Dependency discovery is exact only for a restricted policy language with explicit resource effects. We did not derive a compiler for arbitrary zome code.

**Scope of enforcement.** The mathematical core can express splits, attenuation and joins. The distributed executable restricts transitions to single-controller one-for-one moves, same-owner resets and one committee per batch. The resource model explores all five partitions of three atoms. The unbounded conservation argument assumes trusted genesis and a verifier enforcing a specific transition policy. Conventional BFT or the direct-certificate theorems still supply global input uniqueness. For arbitrary future recipient choice the algebra yields no improvement over the Phase 1 coordination bound.
