# Experiments that could change the decision

1. Run a data-availability experiment in which a Byzantine aggregator disappears after the final vote and Byzantine signers stop responding. Determine when honest replicas can reconstruct the *certificate*, not merely the body. Compare recipient acknowledgements and replicated signature shares; include their extra rounds and privacy cost.
2. Compare the closure rule with a reviewed BFT state machine for the same rights policy on the same hardware, persistence configuration and WAN traces. Measure which real dispute patterns admit a sufficient negative proof and how many assets remain locked.
3. Implement prospective version-bound handoff in the wire format and zome. Model epoch retirement, long-range compromise, collected-but-unpublished handoff, key erasure and verified state transfer before allowing roster changes. Test an unavailable old quorum separately.
4. Extend the bounded policy language with declared guards, lease slots and conservation checks. Differentially test legal interpretations of transfer, expiry and revocation, including minimal forbidden triples. Introduce cross-domain atomic commit only after giving it its own safety and recovery proof.
5. Run distinct administrative and storage failure domains with encrypted authenticated transport. Fault-inject torn writes, media replacement, concurrent clones and stale backups. Verify single signing-instance control, independent failure budgets, audit/alerting and durable outboxes. Add portable proof checkpoints and bounded-cost decoding.
6. Seek independent proof review and an unbounded mechanised refinement from the mathematical protocol through the signer and Holochain verifier. Estimate tail latencies, bandwidth to all recipients, storage growth and validator cost under adversarial input sizes. No finite benchmark can demonstrate the real committee fault bound.
